DATA FLOW
=========

1. INPUT STAGE
   videos/test_video.mp4
         ↓
   VideoProcessor.__init__()
         ↓
   Load video properties

2. SETUP STAGE
   User defines zone (interactive or predefined)
         ↓
   ZoneManager creates polygon
         ↓
   Initialize YOLO model
         ↓
   Create state machine & logger

3. PROCESSING STAGE
   For each frame:
     Read frame (OpenCV)
           ↓
     PersonDetector.detect()
           ↓
     ZoneManager.calculate_overlap()
           ↓
     SafetyStateMachine.update()
           ↓
     SafetyLogger.log_event()
           ↓
     VideoProcessor._annotate_frame()
           ↓
     Display/Save (optional)

4. OUTPUT STAGE
   SafetyLogger.generate_report()
         ↓
   output/logs/log_*.txt
   output/logs/log_*.json
   output/frames/frame_*_STOP.jpg
   output/annotated_video.mp4


CONFIGURATION HIERARCHY
========================

config.py (base configuration)
    ↓
detector.py (uses YOLO_MODEL, CONFIDENCE_THRESHOLD, USE_GPU)
    ↓
zone_manager.py (uses PREDEFINED_ZONE, visualization settings)
    ↓
state_machine.py (uses thresholds, smoothing, hysteresis)
    ↓
video_processor.py (uses output, display settings)
    ↓
logger.py (uses output paths, log level)


MODIFICATION POINTS
===================

To change detection sensitivity:
  → Edit: config.py (CONFIDENCE_THRESHOLD, DANGER_THRESHOLD)

To change model:
  → Edit: config.py (YOLO_MODEL = "yolov8s.pt")

To add hardware integration:
  → Modify: state_machine.py (_on_state_transition method)

To customize logging:
  → Modify: logger.py (log_event, generate_report methods)

To add new features:
  → Create: new module in safety_interlock/
  → Import: in video_processor.py
  → Configure: add settings to config.py
